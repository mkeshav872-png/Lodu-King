## 🎯 How to Play

1. 🎲 **6** aaye to token yard se bahar nikalta hai
2. 🔄 Board par clockwise chalo, phir apni coloured lane se center tak jao
3. ⚔️ Normal square par opponent ka token kaat do to wo wapas yard mein chala jata hai
4. ⭐ Star squares aur start squares **safe** hain, wahan capture nahi hota
5. 🎁 6 aana, capture karna ya token ka home pahunchna **bonus roll** deta hai
6. 🚫 Lagatar teen 6 aaye to tumhari turn chali jati hai
7. 🎯 Home pahunchne ke liye **exact number** chahiye
