# Ludo King by Keshav Mishra
 
A polished Ludo game that runs in any browser. No installation, no dependencies.
 
## Features
- 2, 3 or 4 players, vs Computer or Pass & Play
- 4 computer levels: Easy, Medium, Hard, Pro
- Classic and Quick modes
- Animations, sounds, emoji reactions and quick chat
- 6 themes and 3 pawn styles
- Works on mobile and desktop

## Play
Open the live link (GitHub Pages) or open `index.html` in a browser.
